## What they do
Pose methods for novel objects usually assume either a CAD model (model-based) or a few reference images (model-free), and either estimate or track. FoundationPose covers all four cases with one RGBD network, trained only on synthetic data and applied to new objects without fine-tuning.

## How it works
- **LLM-aided synthetic data.** About 40K Objaverse-LVIS objects plus GSO, retextured by TexFusion from ChatGPT-written appearance descriptions of each object's category, then rendered in Isaac Sim: about 1.2M images.
- **Neural object field.** Without a CAD model, an SDF and appearance network is fit per object from about 16 reference images in seconds, then turned into a textured mesh. Both setups then feed the same render-and-compare modules.
- **Refine, then select.** After 2D detection, 42 viewpoints × 12 in-plane rotations seed the hypotheses. A transformer refiner compares a rendering at each pose with a crop centered on it and predicts translation and rotation updates. A ranking network scores each hypothesis against the observation, then against all the others, and keeps the best. Tracking runs only the refiner, from the previous frame's pose.

## Results
- Model-free, 16 reference images: YCB-Video AUC 91.5 ADD / 97.4 ADD-S vs 42.1 / 88.4 for the fine-tuned FS6D. LINEMOD ADD-0.1d is 99.9 vs 91.5 for FS6D + ICP. With only 4 reference images it still beats FS6D with 16.
- Model-based BOP (LM-O, T-LESS, YCB-V): mean AR 83.3 vs 58.6 for MegaPose-RGBD.
- Tracking on YCBInEOAT: ADD 93.09 vs 92.66 for the instance-trained se(3)-TrackNet; 93.22 when initialized by its own pose estimate.
- On an RTX 3090, estimation takes about 1.3 s per object and tracking runs at about 32 Hz.

## Limitations
It relies on an external 2D detector, and false or missing detections often bottleneck it. It fails on textureless, heavily occluded objects with few edge cues. It needs depth, and reference images need known poses (ground truth in the benchmarks, SLAM in the wild).
