abstract: 'Recent work on robot manipulation has focused on specialist policies trained on demonstrations. We show that generalist AI models can control manipulators more reliably than specialist policies such as vision-language-action models (VLAs) and world-action models (WAMs). We systematically analyze agentic manipulation policies (AMPs), in which a generalist AI model commands the manipulator directly, adapting its actions as the task unfolds. We present AMP1, a reference harness that runs unchanged across single-arm, bimanual, and mobile manipulation. AMP1 achieves state-of-the-art results on the RoboLab-120 and CaP-Gym benchmarks, with no demonstrations or task-specific training. On RoboLab-120, AMP1 reaches an 85.6% success rate zero-shot, compared to 49.2% and 42.9% for leading VLA and WAM policies. The agent succeeds zero-shot in 104 of 108 real-world trials spanning twelve tasks and three robot instances, reducing failure rates by 20x and 15x relative to strong VLA and WAM baselines. The basic harness supplies no grasping, pushing, or placing skills; the agent develops its own strategies, such as searching for hidden objects, using objects as tools, and calibrating its cameras. With the addition of a persistent memory store, the agent can also learn from experience: an augmented harness with a memory representation that is carried across episodes lowers the failure rate on RoboDojo bimanual manipulation tasks by 4.6x relative to zero-shot deployment. Our analysis suggests that AMPs are substantially more general and robust than specialist manipulation policies, providing a promising foundation for robot manipulation.'

## What they do
Instead of training a VLA on demonstrations, AMP1 keeps a general-purpose frontier model (Gemini 4 Argon, Claude Opus 5.5 and others) in the control loop. The model writes code that looks at the cameras, commands the arm and revises its plan after each motion. One harness covers single-arm, bimanual and mobile manipulation in simulation and a real Franka, all zero-shot.

## How it works
- **SDK in a persistent Python interpreter.** Sensing (RGB, depth, calibration, robot state), perception that segments the fused point cloud into tracked objects the model can correct, and helpers to draw plans onto camera images.
- **Motion.** The model sends timed end-effector waypoints and gripper commands; the harness solves IK and refuses unreachable or too-fast trajectories, with a reason. There are no grasp, place or push primitives, so the model writes them itself each episode.
- **Learning from experience (AMP1+).** A persistent memory folder of notes and code that the agent rewrites after reflecting on binary rewards; model weights stay fixed.
- **Real robot.** DROID setup (Franka Research 3, Robotiq 2F-85, two shoulder and one wrist camera), stereo depth, Opus 5.5 at high reasoning, plus SDK calls to recover from collision-reflex stops.

## Results
- RoboLab-120: 85.6% with Gemini 4 Argon and 82.8% with Opus 5.5, against 51.0% for the strongest learned policy on the leaderboard. With vague instructions AMP1 stays at 84.0% / 79.8%, while FLUX 3 Action drops from 42.9% to 28.4%.
- CaP-Gym, zero-shot: 95.2% on LIBERO-PRO, 700/700 on robosuite, 48/50 on BEHAVIOR-1K.
- Real world, 12 tasks with 9 trials each on three robot instances: 104/108 (94/108 without error recovery), against 49 for FLUX 3 Action and 30 for pi0.5.
- The model matters most: Opus 4.5 reaches 35.2%. RGB-only input still gives 75.8% with Opus 5.5, but text descriptions instead of images give 36.8%. Practice with memory lifts RoboDojo bimanual success from 26.4% to 84.1%.

## Limitations
The policy is slow: on the real tasks AMP1 averages 280 s to success, 211 s of it reasoning, against 44 s for FLUX 3 Action. The model cannot react while a trajectory runs, so evaluations are mostly quasi-static. Real-world failures come mainly from collisions, as motion planning is sensitive to camera calibration and uses simplified robot geometry.
