abstract: Enabling vision-language models (VLMs) to control humanoid robots requires both reliable whole-body interfaces and knowledge of how to use the body that carries over across tasks. We present HITCH (Harness Interfaces To Command Humanoids), a harness in which perception returns the 3D position of any point the VLM selects in its image, and execution turns commands for the pelvis, torso, hands, walking, and gaze into whole-body motion with a learned tracker. We find that both measuring the scene and executing commands accurately raise task success. We then fine-tune a VLM on trajectories in which teacher policies solve five base tasks through HITCH, so that it learns how to operate the humanoid. Without task-specific trajectories, the fine-tuned model completes 51% of SIMPLE episodes and 42.5% of HumanoidArena episodes, and adding five trajectories per SIMPLE task raises its SIMPLE success to 95%. On a real G1, it carries a box and walks to a goal without real training data.

## What they do
Pretrained VLMs understand 3D space but know little about how a humanoid body moves, and existing humanoid agents mostly call skill libraries that leave leg and torso posture to the controller. HITCH gives a VLM two interfaces to a Unitree G1, one to measure the scene and one to command each body part. It then fine-tunes Qwen3.8-27B on trajectories of teacher policies that solve five base tasks through the same interfaces, so the model learns where to stand, how low to crouch and what to measure before acting.

## How it works
- **Perception.** The agent picks points in the image from a RealSense D455 on an added 2-DoF head mount. Depth, refined with LingBot-Depth, returns their 3D positions in a robot-centred frame.
- **Execution.** One command sets pelvis height, torso pitch and yaw, palm waypoints, fingers, walking and gaze. A planner solves IK into a whole-body reference that a HEFT tracker follows at 50 Hz. The tracker is further trained on the planner's references.
- **Teachers and training.** Code teachers (written with Claude Opus 5.5) act only on what the agent can observe. 500 successful trajectories per base task (pick-and-place, carrying, navigation, cabinets, room doors) fine-tune the language model, with the vision encoder frozen.

## Results
- With the further-trained tracker, teachers succeed in 97.9% of episodes, against 27.9% with SONIC and 12.9% with AMO.
- Base-task training alone raises success from 3.3% to 51.1% on SIMPLE and from 16.3% to 42.5% on held-out HumanoidArena. Adding 5 SIMPLE trajectories per task reaches 95.0%. Qwen3.8-Max without fine-tuning gets 12.2% on SIMPLE.
- Without the perception interface, base-task SIMPLE success falls to 2.8%.
- Real G1 with rubber hands and no real training data: 13/20 box carries and 6/10 navigation episodes.

## Limitations
The planner does not support motions such as sitting or stepping over obstacles. Each command runs to completion before the agent observes again, so it cannot react mid-motion. Adding SIMPLE trajectories lowers HumanoidArena success, and after fine-tuning, reasoning lowers SIMPLE success because the agent builds on wrong point readings. Hands without finger control limited the real tests to two tasks.
