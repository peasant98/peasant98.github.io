## What they do
LLM-generated programs for social robots usually sit on hand-built control interfaces and stop improving once a task works. EvoMisty is a plugin framework in which a coding agent builds the robot's capabilities from its official documentation, solves tasks with them, optimizes finished programs on user-chosen metrics and distills reusable skills. All experiments run on a physical Misty II with Claude Code and Codex.

## How it works
- **Build.** The agent reads the documentation, lists candidate capabilities, writes a control program and tests each candidate on the robot, using device states and logs, or a yes/no question to a person. Only verified capabilities enter the atomic capability library.
- **Solve.** Task programs combine library capabilities and existing skills. Success criteria are split into automatic checks and human checks.
- **Optimize.** Data hooks record raw inputs, and measurement hooks record timestamps and results. The agent makes one change per iteration, re-measures on replayed or physical runs, and keeps a Pareto front of valid programs.
- **Evolve.** Callable functions from final programs are stripped of task-specific code, verified and added to a versioned skill library.

## Results
- Of 175 documented capabilities, the agents set aside 63 that need hardware Misty lacks. Of the 112 tested, Claude Code verified 109 and Codex 107, about nine times the native capabilities the hand-designed AutoMisty uses.
- Both agents complete all 28 AutoMisty benchmark tasks and 7 new ones, such as gamepad teleoperation and minimal-pair speech therapy. AutoMisty, given the same Opus 5.5 backbone, completes none of the 7.
- Optimization improves all 7 metrics across 5 tasks with both agents. Dialogue latency drops 52% and 71%, line-following lap time drops 37% and 54%, and Claude Code's gesture accuracy rises from 0.845 to 0.987.
- Skills from one optimized dialogue task cut latency by 50% and character error rate by 60% on average in three other dialogue tasks that were never optimized.

## Limitations
Only Misty II is tested. Verification still relies on human observation when logs give no evidence, and only covers conditions the agent can construct. Final performance depends on the agent's first implementation: optimized line-following laps take 20.3 s for one agent and 339 s for the other.
