abstract: 'Large language model (LLM) coding agents can iteratively self-improve robot manipulation skills in simulation benchmarks, yet real-world tasks provide neither ground-truth success scorers nor resettable practice environments. Our key observation is that a single real demonstration simultaneously specifies scene geometry, defines the terminal success criterion, and serves as a physical reference trajectory for verifying world fidelity---all decoupled from the source robot''s kinematics. We present {RESET}: we reconstruct a contact-rich world and derive a frozen read-only criterion from one demonstration ({R}ebuild); check that world against the demonstration by open-loop replay and silhouette consistency ({E}xamine); evolve modular white-box task graphs and skill code from per-node failure evidence ({S}elf-improve); deploy frozen code on real robots with zero runtime LLM calls ({E}xecute); and share the verified world and criterion with unseen robots without new demonstrations ({T}ransfer). On 8 manipulation tasks, each rebuilt from one real demonstration, RESET achieves 97% average success on unseen layouts in simulation, whereas zero-shot code reaches 27%, per-task fine-tuned pi0.5 policies 31%, and Diffusion Policy 50%; injecting reconstruction defects shows that practice tolerates many reconstruction errors, that geometric errors can still stall or mislead it, and that the check flags most of them while physical randomization covers the rest. Without any target demonstrations, 3 heterogeneous robots acquire the same task skills in the shared world: a robot with similar arms copies 95% of its skill functions unchanged from the source robot, while robots with different arms and hands write their own. In real-robot experiments, the resulting programs run on 4 robots and succeed in 80% of 280 trials.'

## What they do
LLM coding agents can improve robot code by trial and error on simulation benchmarks, but a real task has no resettable world and no automatic scorer. RESET gets both from one real demonstration: the first RGB-D frame gives the scene, the final state defines success, and the recorded motion is a reference for checking the rebuilt world. Other robots then practice in the same world without a demonstration of their own.

## How it works
- **Rebuild.** SAM3 segments the objects, a coding agent models each as a mesh registered to the first-frame depth, and the scene goes into MuJoCo. The success criterion is a set of geometric relations read from the final state, confirmed once by a person and hidden from the controller.
- **Examine.** The recorded joint and gripper commands are replayed open-loop (objects move only through contact) and rendered silhouettes are compared with the demonstration masks. Mass and friction cannot be checked this way, so practice randomizes them.
- **Self-improve.** The program is a task graph plus a skill library. Claude Code reads per-node failure reasons and keyframes, edits the graph or a skill, and keeps an edit only if it does better on hold-out layouts.
- **Execute and transfer.** Frozen code runs with no LLM calls. Target robots supply their URDF, calibration and contact offsets and practice in the shared world.

## Results
- Simulation, source robot, 50 unseen layouts per task: 97% average over 8 tasks, against 27% for zero-shot code, 31% for per-task fine-tuned π0.5 and 50% for Diffusion Policy.
- Without demonstrations, Dual-arm Franka reaches 95.5%, ARX LIFT2 79.5% and Unitree G1 77.3% in simulation. Franka reuses 94.5% of its skill functions unchanged; G1 writes 86.7% from scratch.
- Real robots: 223 of 280 trials succeed (xTrainer 73/80, Franka 76/80, LIFT2 61/80, G1 13/40). Simulation and real outcomes agree in 95% of xTrainer trials and 90% of LIFT2 trials.
- Examine flags 13 of the 16 injected geometric errors that break a skill.

## Limitations
Only rigid, articulated and quasi-static sweeping tasks; no cloth or throwing. Randomization cannot cover changes that need a different contact strategy (a 3x heavier drawer stays unsolved). Practice does not model the humanoid's whole-body controller, so G1 succeeds in 33% of real trials against 84% in simulation on the same tasks.
