abstract: Robots should adapt to unfamiliar environments and acquire new skills through interaction, then execute those skills efficiently with practice. Vision-language-action policies provide efficient control, but often need additional human demonstrations to handle unfamiliar settings; reasoning agents can discover solutions using broad prior knowledge and robot-control APIs, but repeated deliberation and repair are costly. Inspired by human learning through reasoning and practice, we propose RoboEvo$^2$, a framework for recursive harness-policy co-evolution. In Policy-to-Harness (P2H) evolution, policy failures guide a coding agent to search complementary Code, Code+ICL, and Code+Policy routes, consolidating verified solutions into reusable skills, routing strategies, and experience memory. In Harness-to-Policy (H2P) evolution, verified trajectories provide supervised training, while Counterfactual Preference Distillation (CPD) teaches the policy to favor successful corrections over failures from the same starting state. The improved policy provides stronger motor skills for subsequent search, while its remaining failures redirect harness evolution, closing the reciprocal loop. Through recursive co-evolution without additional human demonstrations, RoboEvo$^2$ improves standalone success from 11.0% to 84.1% and hybrid success from 30.4% to 90.5% on LIBERO-PRO, with similar gains and reduced agentic costs on RoboTwin C2R. Further experiments demonstrate autonomous task acquisition, cross-embodiment harness transfer, and 95.0% hybrid success on the Unitree G1-D. Our models and code will be publicly released.

## What they do
VLA policies need new human demonstrations to cope with unfamiliar scenes, while coding agents can find fixes but are slow and costly to run on every episode. RoboEvo² alternates the two. The current policy's failures send a coding agent looking for verified repairs, which become reusable skills in its harness. The policy is then retrained on those repairs, and its remaining failures start the next round. No additional human demonstrations are used.

## How it works
- **Policy-to-harness.** For each failed rollout, a VLM coding agent (GPT-6 Astra) searches three routes in parallel: code skills alone, code guided by one in-context demonstration, and code that calls the policy as a motor primitive. Among verified successes it keeps the one with the lowest normalized jerk and merges compatible changes into the skill library, memory and routing rules.
- **Harness-to-policy.** Successful rollouts and repaired trajectories are used for supervised fine-tuning. Counterfactual Preference Distillation pairs a failed and a repaired continuation from the same state and trains the policy to prefer the repair, relative to a frozen reference. Failure-weighted task sampling and EWC limit forgetting.
- **Two execution modes.** Standalone runs the policy alone; hybrid lets the agent route each step to the policy or a code skill. An update is kept only if it raises success.

## Results
- LIBERO-PRO (π0.5, eight rounds): standalone success goes from 11.0% to 84.1% and hybrid from 30.4% to 90.5%, while API cost per round drops from $430.63 to $98.92. Adding PPO gives 94.8% and 96.8%; EmbodiedRSI reaches 86.8% hybrid.
- RoboTwin C2R (50 bimanual tasks, five rounds): standalone goes from 46.0% to 77.5% with 7.5K trajectories, matching the 76.8% of training on 27.5K that include randomized demonstrations.
- After three rounds, full co-evolution reaches 52.3% standalone, versus 33.6% when the harness is frozen.
- Unitree G1-D, four bimanual tasks, 10 trials each: the harness transferred from simulation succeeds 47.5% of the time and collects 120 demonstrations. The policy trained on them reaches 85.0%, versus 80.0% for π0.5 trained on 200 teleoperated demonstrations, and 95.0% in hybrid mode.

## Limitations
The harness composes a fixed set of atomic skills and perception tools that lack force-controlled contact and in-hand regrasping. Training data are selected by a task-level success check. On the real robot an operator resets the scene to the pre-failure state before each repair, one policy is trained per task, and each task has only 10 trials.
