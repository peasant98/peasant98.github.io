abstract: Diffusion and flow-matching policies have become a standard choice for visuomotor imitation learning, owing to their ability to model multimodal action distributions. In memory-dependent manipulation, the robot must act on information that is no longer visible. Existing methods feed the observation history to the policy as an additional condition, while action generation still starts from Gaussian noise. However, the policy must then pick out the relevant target from a long and redundant history, leading to spurious correlations and unreliable decisions as the memory load grows. Additionally, the initial noise carries no information about what the robot has seen, leaving generation without guidance toward the remembered target. To address these issues, we propose RecallFlow, a flow-policy framework that builds the source distribution from episodic memory. Recall-Relocalization relates the memory to the current view through a few recall slots, so that the source reflects where the remembered targets are now. Recall Anchors then turns each slot into a Gaussian component of the source, enabling generation to start close to the intended action instead of from noise. The transport network then completes the action from the current observation alone, keeping inference nearly as cheap as a memoryless policy. We further build a suite of memory-dependent tasks grouped by memory load and compare all policies under a matched protocol. Extensive experiments show that RecallFlow achieves a state-of-the-art average success rate of 80.4% on the public MIKASA-Robo memory benchmark, and outperforms the strongest baseline by 20.3 points on our suite and by 18.8 points on four real-robot tasks.

## What they do
In memory-dependent manipulation the cue that decides the action, such as which cup hides the ball or which containers were already touched, is gone by the time the robot acts. History-conditioned diffusion and flow policies feed past frames in as a condition but still start generation from Gaussian noise. RecallFlow puts the episodic memory into the source distribution of a flow policy instead: memory decides where generation starts, and the current view decides how to get there.

## How it works
- **Memory bank.** After each action chunk, SigLIP 2 patch tokens from the wrist and third-person cameras are stored with camera, position and age embeddings (32 entries; the most similar adjacent entries merge when full).
- **Recall-Relocalization.** The current tokens read the bank through memory attention; 4 learnable recall slots read the memory, then the current view through a heatmap, so each slot reflects where a remembered target is now.
- **Recall Anchors.** Each slot becomes a Gaussian over the action chunk. Together with a no-recall standard Gaussian they form a mixture source, trained by maximum likelihood rather than the flow loss, which would reward narrow anchors over correct ones.
- **Transport.** A DiT that sees only the present refines the source sample into actions, adding 1.1 ms per chunk over the memoryless policy.

## Results
- RecallSuite (5 simulated tasks, 3 seeds): 84.6% average vs 64.3% for long-history Diffusion Policy; 64.7% vs 15.0% on NoRepeat-4.
- MIKASA-Robo: 80.4% average vs 75.1% for the best published method.
- RoboMimic Square, which needs no memory: 89.0% vs 86.2% for the memoryless flow policy, while long-history DP drops below memoryless DP.
- Real xArm 7, 24 trials per task: 82.3% vs 63.5% for long-history DP and 18.8% without memory; Remember Color 83.3% vs 37.5%.

## Limitations
The memory stores frames of single-arm tabletop scenes at fixed capacity, so tasks with a long, dense relevant past may need a summarizing memory. Policies are single-task and not language-conditioned, and real-robot policies use one training seed. On RememberColor9 it scores 36.3% vs 53.3% for Chameleon.
